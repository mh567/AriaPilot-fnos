# AriaPilot fnOS v1.0.8

本次更新改进了外部 aria2 模式：连接成功后会自动读取服务端的下载目录、并发任务数、每任务连接数、分片数和全局限速，保存时写入 aria2 服务端全局配置，设置页会显示连接状态和保存结果。

## 资产

- `ariapilot_1.0.8_x86.fpk`
- `ariapilot_1.0.8_arm.fpk`
- `SHA256SUMS-v1.0.8.txt`

## 安装与升级

在飞牛应用中心选择手动安装，按设备架构选择 x86 或 arm 包。已安装旧版本时直接安装新包即可升级，原有设置和任务记录保留。

外部模式的目录是 aria2 服务端路径，不受飞牛授权目录限制。连接失败时仍可保存 RPC 地址与密钥，但目录和线程参数不会写入服务端。

## 已知限制

- 外部模式不支持删除远端文件，也不支持浏览本机目录
- ARM64 包尚未在真实 ARM 设备上验收
- 任务列表不按飞牛用户隔离

安装、配置和排障见 [docs/FNOS.md](https://github.com/mh567/AriaPilot-fnos/blob/main/docs/FNOS.md)。
