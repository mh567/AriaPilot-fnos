# AriaPilot fnOS v1.0.7

这是 AriaPilot fnOS 版迁移到独立仓库后的首个版本，代码与主仓库的 `fnos-v1.0.7` 发布一致。

## 资产

- `ariapilot_1.0.7_x86.fpk`
- `ariapilot_1.0.7_arm.fpk`
- `SHA256SUMS-v1.0.7.txt`

## 安装

在飞牛应用中心选择手动安装，按设备架构选择 x86 或 arm 包。安装完成后桌面会出现 AriaPilot 图标。

默认下载目录为应用共享目录 `ariapilot/downloads`。需要其他目录时，先在「系统设置 → 应用 → AriaPilot → 访问权限」授权读写，再在应用内选择。

## 本次包含

- 内置 aria2 引擎的启动、停止、重启和设置应用串行化
- 启动失败保留退出码、信号和标准输出摘要
- 内置引擎 HOME 固定为应用数据目录，修复设备上的启动崩溃
- 删除任务时清理 `.aria2` 控制文件
- 默认下载目录不再重复 `downloads`
- 默认入口引用与实际图标文件名对齐

## 已知限制

- 桌面图标修复仍需在目标设备上验收
- ARM64 包尚未在真实 ARM 设备上验收
- 外接存储的 exFAT、FAT32、NTFS 分区可能只能授权为只读
- 任务列表不按飞牛用户隔离
