# AriaPilot fnOS v1.0.9

本次更新集中改进设置页。设置页不再显示下载统计和新建下载按钮，保存按钮固定在右下角，并增加未保存提示和离开确认，避免修改丢失。

外部 aria2 模式不再在地址变化时自动覆盖已填参数，读取服务端配置改为明确操作。授权目录增加选中状态，引擎模式切换和状态提示也补充了无障碍语义。

## 资产

- `ariapilot_1.0.9_x86.fpk`
- `ariapilot_1.0.9_arm.fpk`
- `SHA256SUMS-v1.0.9.txt`

## 安装与升级

在飞牛应用中心选择手动安装，按设备架构选择 x86 或 arm 包。已安装旧版本时直接安装新包即可升级，原有设置和任务记录保留。

## 已知限制

- ARM64 包尚未在真实 ARM 设备上验收
- 任务列表不按飞牛用户隔离

安装、配置和排障见 [docs/FNOS.md](https://github.com/mh567/AriaPilot-fnos/blob/main/docs/FNOS.md)。
